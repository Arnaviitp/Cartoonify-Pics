# Cartoonify-Pics

## Overview
The **Cartoonify Pics** project is a Jupyter Notebook that applies cartoon effects to images using OpenCV and other image processing libraries. This project converts real-world images into cartoon-style visuals by applying various filters and edge detection techniques.

## Features
- Converts images into cartoon-like visuals
- Uses OpenCV for image processing
- Applies edge detection and bilateral filtering
- Allows users to input custom images

## Requirements
Before running the notebook, ensure you have the following dependencies installed:

```bash
pip install opencv-python numpy matplotlib
```

## Usage
1. Clone the repository or download the notebook.
2. Open the notebook in Jupyter or Google Colab.
3. Run the cells sequentially to execute the cartoonify process.
4. Upload an image and view the cartoonified output.

## Example Output
After running the notebook, the input image will be processed and displayed as a cartoonified version.
